# LogiLedger

**Smart Inventory & Credit Management System**

LogiLedger is a full-stack business platform designed to help small shopkeepers manage product inventory, customer-wise transactions, credit/debit records, expiry tracking, and AI-powered stock refill suggestions — all in one place.

> 🚧 This project is currently under development. Live deployment and full functionality will be available soon.

---

## 🔧 Key Features (Planned)

- 🔐 Role-based login system for shopkeepers and customers
- 📦 Inventory management with approval-based stock transfers
- 👤 Customer-wise sales, purchases, and credit/debit tracking
- ⏰ Expiry alerts for perishable or time-sensitive products
- 🧠 AI-powered recommendations for stock refilling
- 📊 Interactive dashboards with charts and filters

---

## 📦 Tech Stack

**Frontend**: ReactJS · TailwindCSS · Recharts  
**Backend**: Node.js · Express · MongoDB  
**Authentication**: JWT (JSON Web Tokens)  
**Hosting**: Vercel (Frontend) · Render (Backend) · MongoDB Atlas (Database)
